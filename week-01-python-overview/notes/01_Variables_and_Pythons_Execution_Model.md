# Variables and Python's Execution Model

## Learning Outcomes
Explain how Python names refer to objects, how assignments work, and how expressions produce values.

## Learn - 30 minutes
- Watch the Variables lesson.
- Investigate strings, numbers, booleans, arithmetic, None, and simple functions.
- Compare Python's assignment and expression behaviour with TypeScript.

## Practice - 30 minutes
Build a task summary from primitive values. Represent a task's title, estimated hours, completion state, and optional description. Derive a readable summary from those values.

## Acceptance Criteria
- The script runs from the terminal.
- You can modify its inputs without changing the summary logic.
- You can explain the difference between a name, the object it refers to, and a value produced by an expression.
