# Functions, Type Hints and Conditionals

## Learning Outcomes

Separate computation from presentation and express business rules as small, understandable functions.

## Learn - 30 minutes

- Watch the Functions, Type Hints & f Strings, and Boolean & Truthy lessons, prioritising functions and conditionals if time runs short.
- Investigate parameters, return values, annotations, f-strings, `if`/`elif`/`else`, and truthiness.
- Pay attention to the difference between returning a value and printing it.

## Practice - 30 minutes

Extract the task's overdue calculation and status description into functions. Add rules for completed tasks, tasks with no deadline, and tasks whose deadline has passed.

## Acceptance Criteria

- The overdue rule is reusable and testable by calling a function.
- The function returns a boolean or another clearly defined result instead of printing internally.
- Type hints describe the intended inputs and outputs.
- You can predict how the logic behaves for missing values and completed tasks.

## Scope Notes

Use straightforward functions and conditionals. Avoid unrelated design patterns, abstractions, or advanced error handling.
