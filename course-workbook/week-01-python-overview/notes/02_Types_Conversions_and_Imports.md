# Types, Conversions and Imports

## Learning Outcomes

Understand Python's dynamic typing and use standard-library functionality instead of reimplementing common operations.

## Learn - 30 minutes

- Watch the Types & Imports lesson (00:39:05–00:46:36).
- Investigate `type()`, explicit conversions, comparisons, and type hints.
- Explore `datetime`, `pathlib`, and `collections` at a basic level.

## Practice - 30 minutes

Extend the task summary with a due date. Parse or construct a date, calculate whether the deadline has passed, and format a useful output.

## Acceptance Criteria

- A task can have a due date and an optional description.
- Date handling uses the standard library rather than manually comparing date strings.
- You can explain the difference between a value's runtime type and a type annotation.

## Scope Notes

Conditionals are covered on Day 04. On this day, focus on constructing and comparing date values and understanding the resulting boolean without prematurely introducing `if`/`else` branching.
