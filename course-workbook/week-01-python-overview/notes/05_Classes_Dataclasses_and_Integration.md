# Classes, Dataclasses and Integration

## Learning Outcomes

Choose a sensible representation for related data and integrate the week's concepts into one coherent program.

## Learn - 30 minutes

- Watch the Classes and Fundamentals Exercise lessons.
- Compare a regular class with a dataclass.
- Investigate initialisation, attributes, equality, and readable representations.

## Practice - 30 minutes

Refactor the task data into a `Task` dataclass. Integrate its enum status, deadline, and evaluation functions. Run the program with several different task scenarios.

## Acceptance Criteria

- The model and evaluation logic are separate from the CLI output.
- The program handles completed, overdue, upcoming, and deadline-free tasks correctly.
- You can explain why you chose a dataclass instead of a dictionary or regular class.
- You can make one small change without copying the course implementation.

## Scope Notes

Build on the concepts from Days 01–04. Prefer the simplest design that meets the requirements, and avoid adding abstractions that are not needed for this exercise.
